## Как развернуть на GitHub Pages

1. Создайте репозиторий на GitHub (например, `titus`)
2. Подключите его:
   ```bash
   git remote add origin https://github.com/<username>/<repo>.git
   git branch -M main
   git push -u origin main
   ```
3. В настройках репозитория: **Settings → Pages → Deploy from branch → main → / (root) → Save**
4. Через минуту весь мир будет доступен по адресу:
   `https://<username>.github.io/<repo>/`

Относительные ссылки уже настроены — `index.html` ведёт во все комнаты.
